# 긴 작업의 진행 표시와 잠정 요약

이 문서는 현재 Maeklog 소스의 공개 진행 표시·요청형 요약 동작을 설명합니다. 사용법은 [사용 안내](usage.md), 설치·검증 범위는 [배포 준비 상태](release-readiness.md)를 참고하세요. [2026-10-02 적용 기록](verification-live-progress-2026-10-02.md)은 원래 구현의 익명화한 역사적 참고 자료입니다.

## 작업 중에 보이는 것

Codex가 한 답변 안에서 몇 시간 동안 작업해도 Maeklog 기본 화면에 최근 공개 설명을 표시하고, 메뉴의 **진행 상황 보기**에서 현재 요청·공개 설명·작업 계획·도구 활동을 읽을 수 있습니다. Codex가 이미 만든 공개 기록을 읽는 화면이므로 **추가 모델 호출은 0회**입니다. 기록이 들어올 때 로컬 상태를 바꾸며, 패널은 기존 1초 화면 갱신을 사용합니다. 3~5분마다 요약하는 타이머는 없습니다.

계획의 ‘완료 보고’는 Codex가 표시한 단계 상태입니다. 도구 종료나 응답 종료만으로 프로젝트 전체 완료를 판정하지 않습니다. 중간 설명이나 계획이 없는 작업에서는 요청·도구 정보만 표시하고 남은 단계나 완료율을 추측하지 않습니다.

## 필요할 때만 요약

Maeklog에서 **`s`**를 누르거나 우클릭 메뉴의 **진행 상황 요약**을 선택하면 그 시점까지 수집한 기록을 한 번 정리합니다.

1. 누른 시점의 기록을 고정하고 요청을 대기열에 넣습니다.
2. 기존 완료 요약 작업이 있으면 그것을 먼저 처리합니다. 기존 Space별 한 작업, 전체 모델 호출 최대 3개의 제한을 공유합니다.
3. 준비한 기록으로 현재 작업·보고된 진척·명시된 남은 확인을 짧게 정리합니다. 화면에 ‘잠정’과 기록 기준 시각을 표시합니다.
4. 생성 중 새 활동이 들어와도 요청 범위가 커지지 않습니다. 새 활동은 자동 진행 화면에 표시하고 기존 잠정 요약에는 ‘요청 후 새 활동 있음’으로 구별합니다.
5. 같은 기록 버전·모델·추론 강도·실제 언어에서 다시 누르면 저장한 결과를 재사용합니다. 생성 중 연속으로 누른 요청도 하나로 묶습니다. 실패한 요청은 자동으로 재호출하지 않으며 `s`로 다시 요청합니다.

이 요청은 메뉴에서 선택한 **요약 모델·추론 강도·언어**를 요청 시점에 고정합니다. 기본값은 **gpt-6-luna / medium · Standard**입니다. 같은 기록·모델·강도·실제 언어일 때만 캐시를 재사용합니다. 180초 제한, 읽기 전용·일회 실행, 사용자 설정 무시, 내부 훅 비활성화를 적용합니다.

## 기존 요약과의 관계

자동 진행 정보는 `live-turn.json`, 요청한 잠정 요약은 `live-summary.json`에만 저장합니다. 기존 대화 대기열·처리 커서·결정 및 완료 원장에 넣지 않습니다. 주 Codex 대화에도 주입하지 않습니다.

최종 답변이 들어오면 진행 중 잠정 요약을 취소하고 기존 완료 대화 요약으로 넘어갑니다. 기존 요약이 저장되면 해당 진행 표시를 치웁니다. 완료 대화의 오늘 자동 / 이전 날짜 수동 정책도 유지합니다.

사용자가 중간 요약을 요청한 경우에는 그 한 번의 추가 호출 비용이 있습니다. 최종 요약은 기존 방식으로 완료 대화를 처리하므로 중간 요약에 본 내용과 일부 겹칠 수 있습니다. **자동 중복 호출은 없지만, 요청형 중간 요약과 최종 요약의 입력 재독까지 없앤 설계는 아닙니다.**

## 범위와 한계

- 새 브릿지가 들어간 Codex 터미널 클라이언트와 새 Maeklog 수신기·패널이 함께 필요합니다. 기존 클라이언트는 정상 종료 후 같은 터미널에서 재개해야 합니다. 적용 전 시작한 작업의 중간 활동을 거슬러 복원하지 않습니다.
- 터미널의 활성 주 대화만 수집합니다. 다른 탭·하위 에이전트·내부 요약 작업의 기록을 현재 작업에 섞지 않습니다. 턴 시작 위치로 연결하고, 종료 뒤 늦게 도착한 활동은 진행 상태를 다시 열지 못합니다.
- 수집 끄기·기록 삭제·세션 및 브랜치 변경을 따르면 잠정 상태와 요청도 무효화합니다. 껐다 켠 뒤 제외했던 진행 기록을 다시 살리지 않습니다.
- 최근 설명 최대 24개, 도구 상태 최대 24개, 계획 최대 16단계를 보관합니다. 중간 설명은 항목당 1,200자이며, 요약 입력은 직렬화한 근거 합계 16,000자로 제한합니다. 생략된 기록이 있으면 화면에서 알립니다. 수시간의 전체 대화를 압축하는 기능은 아닙니다.
- Codex 브릿지는 고정 크기 대기열에서 기록을 합쳐 전달합니다. 끊김·종료·밀린 대기열에서는 일부 기록을 놓칠 수 있습니다. 수집 시각은 Maeklog이 받은 시각이며 마지막 활동을 새로 관측한 것처럼 갱신하지 않습니다.
- 추론 내용·토큰 조각·도구 인자·결과·명령 출력·파일 diff는 수집하지 않습니다. 공개 중간 설명과 명령·파일 경로·검색어 같은 활동 표시는 로컬 캐시에 포함될 수 있습니다.
- 모의 모델 검사로 호출·캐시·취소·분리 동작을 검증합니다. 실제 선택한 모델이 만드는 잠정 요약의 의미 정확도·품질은 별도 평가 대상입니다.
