Maeklog 로고 · 02번 시안

선택한 02번 시안을 기준으로, 둥근 ㅁ에서 곡선형 ㄹ로 흐르는 심볼을 벡터 패스로 다시 그렸습니다. 래스터 이미지를 SVG 안에 넣은 파일이 아닙니다.

파일 안내
- symbol: 심볼 단독, 정사각형 캔버스
- horizontal: 심볼 + Maeklog 가로 조합
- stacked: 심볼 + Maeklog 세로 조합
- black: 검정 로고, 밝은 배경용
- white: 흰색 로고, 어두운 배경용
- SVG: 확대해도 선명한 벡터 원본. 심볼과 글자는 모두 패스이며 폰트 설치가 필요 없습니다.
- PNG: 배경이 투명한 고해상도 이미지. 심볼은 2048px, 조합형은 가로 3200px입니다.
- preview.jpg: 밝은 배경과 어두운 배경의 확인용 미리보기입니다. 제작용 원본에는 배경이 없습니다.

사용 권장
SVG는 웹·인쇄·편집 원본으로, PNG는 슬라이드·문서·프로필 등에 사용하세요. 가로세로 비율을 유지하고, 심볼 폭의 약 15% 이상을 여백으로 확보하는 것을 권장합니다. 작은 크기에서는 심볼 단독을 사용하고 실제 표시 크기에서 가는 흰 틈의 가독성을 확인하세요. 흰색 파일은 흰 배경에서 보이지 않는 것이 정상입니다.

제작 참고
생성된 콘셉트를 바탕으로 실사용할 수 있도록 외곽선을 수작업 벡터로 정리했습니다. 원본 시안의 픽셀 단위 복제본은 아닙니다. 워드마크는 Nimbus Sans Regular 기반의 윤곽선이며, 원본 시안의 글꼴을 정확히 복원한 것은 아닙니다. 심볼은 단색 #000000 / #FFFFFF입니다.

상표 등록 가능성, 타 로고와의 유사성 및 법적 권리 검토는 수행하지 않았습니다. 상업적 적용이나 상표 출원 전 별도 확인을 권장합니다.
