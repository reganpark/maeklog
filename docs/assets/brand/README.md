# Maeklog 로고

Maeklog의 일곱 알파벳 `m a e k l o g`를 조합해 두 음절 **맥락**의 획을 만든 로고입니다. 가까이에서는 알파벳을, 전체에서는 한글 형태를 볼 수 있도록 설계했습니다.

## 파일

| 파일 | 용도 |
| --- | --- |
| [maeklog-logo.svg](maeklog-logo.svg) | 청록색 벡터 원본. 밝은 배경의 기본 로고 |
| [maeklog-logo.png](maeklog-logo.png) | 같은 로고의 투명 PNG, 1796 × 1106 px |
| [maeklog-logo-dark.svg](maeklog-logo-dark.svg) | 어두운 배경에 쓰는 흰색 벡터 원본 |
| [maeklog-logo-dark.png](maeklog-logo-dark.png) | 같은 흰색 로고의 투명 PNG, 1796 × 1106 px |

두 색상 파일은 같은 로고의 배경 대응 버전입니다. 벡터 원본의 `viewBox`는 `0 0 898 553`이며, 기본 색은 `#458588`, 어두운 배경용 색은 `#ffffff`입니다.

## 글자 구성

- 첫 음절의 네모꼴은 큰 `o`가 만듭니다. 두 `l` 기둥과 중앙의 `ae`가 `ㅐ`를 구성합니다.
- 두 받침의 가로획은 `maeklog` 글자 행이며, 마지막 `g`의 꼬리에서 이어지는 `l`이 오른쪽 세로획을 만듭니다.
- 두 번째 음절의 `ㄹ`은 같은 크기의 `log` 세 행과 `l` 반환으로 구성합니다. `ㅏ`는 긴 `l`과 짧은 `o` 팔로 만듭니다.

소문자 일곱 종류의 윤곽을 반복해 총 34개 문자 부품을 사용합니다. 각 부품의 길이와 비율을 조정해 전체 한글 실루엣을 구성했습니다. 완벽한 양방향 앰비그램을 표방하지 않습니다.

## 사용

README에서는 가로 360 px를 권장합니다. 가로 180 px에서도 실루엣을 검수했지만 작은 크기에서는 알파벳의 세부가 줄어듭니다. 헤더와 README용으로 설계했으며 작은 파비콘에서의 가독성을 보장하지 않습니다.

가로세로 비율과 파일에 포함된 여백을 유지하세요. 밝은 배경에서는 기본 청록색 파일을, 어두운 배경에서는 `-dark` 흰색 파일을 사용합니다.

## 제작 근거

제작 요청은 “Maeklog 알파벳을 사용해 ‘맥락’ 모양을 만들기”입니다.

최종 자산은 **직접 작성한 벡터 로고 원본**입니다. 일곱 종류의 라틴 글자 윤곽을 새로 그려 SVG 내부에서 반복 배치했습니다. 외부 폰트·이미지·링크에 의존하지 않습니다. PNG는 이 SVG의 2배 크기 렌더링입니다.

초기 탐색에 사용한 기본 이미지 생성 도구의 래스터 시안은 채택하지 않았으며 이 폴더에 포함하지 않습니다. 최종 파일은 래스터 추적이나 이미지 삽입 없이 설계한 원본 SVG와 그 PNG 렌더링입니다.

청록색과 흰색 파일을 밝고 어두운 배경에서 가로 360 px·180 px로 검수했습니다. SVG XML, 외부 참조 유무와 PNG의 투명 채널도 확인했습니다.
