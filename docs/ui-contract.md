# Maeklog panel contract — 2026-10-13

The panel puts current dialogue work and collected public progress before this tab's saved branch records. It does not independently verify reports, grant approval, or execute the next recorded action.

Local timestamps display as YYYY/MM/DD HH:mm without a repeated numeric UTC offset. Main previews shorten a cached timestamp to HH:mm only when its local date matches the displayed day; other dates and unknown times retain their full meaning. UTC epoch storage, source-evidence clocks and local timezone/DST conversion remain unchanged.

## Language preference and model settings

The language picker offers **Auto**, **English** and **한국어**; Auto is the default. Its visible Auto label is **자동 / Auto**, and the menu entry **언어 / Language…** remains discoverable in both languages. Up/down changes only the cursor; Enter or an item click saves, Esc cancels. Preference is shared by panels using the same app configuration directory. A save immediately changes fixed UI text in the current panel; other open panels refresh on their approximately one-second settings poll.

Auto resolves the first nonempty LC_ALL, LC_MESSAGES, then LANG: Korean locales use Korean; English, unsupported, C/POSIX and unset locales use English. Explicit English or 한국어 overrides that resolution. Desktop language preferences and LANGUAGE are not queried separately. The system locale used by Auto remains fixed on first process use; app preference changes do not require restart. An Auto process must restart to observe a changed environment locale.

Source requests, evidence quotations, reference titles, model-produced saved content and older records retain their original language. Rendering does not translate user text or trigger a model call. New summary prompts request the freshly resolved preference language while keeping source evidence unchanged. Roles derive from typed status and action identity, not translated body keywords.

m's **요약 모델… / Summary model…** opens bounded Codex catalog discovery. Up/down selects a model, Enter proceeds to its supported reasoning efforts, and Enter on an effort saves the Maeklog-wide selection. Esc returns or closes without saving; r refreshes only the catalog. A model without effort options has no effort override. Current settings remain visible and unchanged if the catalog fails or lacks that model. Catalog metadata may be bundled or cached and does not establish account entitlement.

Model settings and language preference are global to the Maeklog configuration directory and do not change Codex's general configuration. Language preference uses language-settings.json with auto/en/ko values and a separate lock. Malformed/oversized/symlink preferences or lock/write failures preserve existing bytes and the last cached UI language; an invalid preference blocks a new inference profile rather than silently substituting another language. An explicit HERDR_PLUGIN_CONFIG_DIR wins; a namespace-owned installed bin/maeklog-hook with valid co-located hook-runtime.json uses that config parent, otherwise the canonical Herdr Maeklog directory applies. A recognized malformed runtime fails without redirecting settings. State-directory resolution gives an explicit MAEKLOG_STATE_DIR first priority, then the installed runtime from the selected configuration directory, then HERDR_PLUGIN_STATE_DIR and the XDG default. Reusing a store requires a one-time explicit runtime path; there is no automatic migration or legacy-store fallback. Opening, cancelling or saving the picker neither summarizes a conversation nor rewrites saved records. Completed-turn reduction captures model/effort/language when inference starts; live summary requests capture them on explicit request. Same-snapshot reuse requires an identical model/effort/resolved-language profile. Auto and an explicit preference resolving to the same language may reuse that cache. A newer explicit request replaces the prior pending request, and stale results cannot overwrite it, including when settings change A → B → A. Existing ready legacy results are readable but are not reused for a new request; old queued/running entries require an explicit new request.

## Reading order

Repository, observed branch and transferred worktree identify the location. The main view has two major sections:

1. **현재 대화의 작업**: assigned current references and related PRs, then the latest collected public explanation. An unlinked reference and its candidates share one information block with the l shortcut. A blank line separates references from the explanation heading; its time identifies the explanation, and its response status appears only once. Body paragraphs use a two-cell inset. A recent user request is auxiliary context, not a work title. Response end is not work completion. Missing progress is neutral “진행 정보 없음.” Reference absence, explicit no-link and failed verification are separate from missing live progress.
2. **이 탭의 저장 기록 · BRANCH**: confirmed decisions, today's completion reports, recorded progress, blockers, next actions and conditions. Existing branch records are not attributed to the current dialogue or a transferred worktree.

The default view includes the whole latest collected public explanation, all valid decisions, today's completions, recorded progress, blockers and next actions. Long bodies, reference titles and conditions wrap fully and remain reachable by scrolling. Each saved item groups its time, report type/owner and body with a bullet, hanging indent and space between items. Original reports are not merged because they sound similar. Last inclusion time and this tab's unreflected completed-turn counts form one neutral saved-status group. Today's and earlier/held turns remain separately labelled; they count completed dialogue turns, not raw events, completion reports or the current response's progress. Actual collection gaps and saved-record read errors retain their scoped explanations. Recorded blockers use bright normal body text with their original source time, owner and full report; they do not claim the current dialogue is blocked. Actual unresolved failed/rework follow-ups retain their warning and full content.

When a public explanation is present, the full recent request is available in m's progress details. Without one, the main view displays the entire recent request under its own heading. The request never becomes a work title. Upstream capture limits remain explicit; displaying the whole cached explanation cannot recover content that was never collected.

Normal zero-count queues and repeated internal identifiers move to collection details. A record-summary failure has one status heading, an authored explanation of a known cause when supported, and one recovery line. Today uses r to retry; a selected earlier date uses b to reselect the date. Both offer h for summary/processing details. Retry-wait/exhaustion and an explicitly requested date retain visible feedback. A ready same-revision temporary summary has a route to its full collected content. Zero-count queues imply neither response end nor task completion. Failure and exhaustion are recomputed from the current durable retry budget; a stale raw last-worker error does not establish either. Technical diagnostics and raw event units remain in h's record summary/processing category.

A bounded collected history is not a current collection failure. The normal partial-history flag and participation generation are explained in collection details without a main-view gap warning. Actual journal gap evidence remains visible as a past collection gap. Scope attribution failures retain their own explanation. None of these records is deleted or converted into proof that all past dialogue was collected.

No matching evidence means unknown/empty, not “no blockers” or “PR does not exist.” Explicit no-link is a user association choice. A current target's metadata error stays beside that target; a new explicit B does not revert to previous A on error. Legacy branch cache metadata/errors remain available in link selection and full record details rather than becoming the dialogue work title. Unbound or ambiguous native clients keep the picker open-only. Item evidence, dialogue reflection, journal update, live activity, summary-request and GitHub-check clocks remain separate. Unknown time is not replaced by file modification time.

## Interaction

Left drag in main or a reader selects Maeklog text by terminal cells (including wide Korean characters); release requests an OSC 52 clipboard write, capped at 64 KiB. Frozen rows prevent refresh from changing selected text. The selection adds no model/GitHub calls or record writes. The first Esc clears selection; a subsequent reader Esc returns to main. Other keys, resize, scrolling and an effective-language change dismiss selection. Language-change selection dismissal is explained visibly. Clipboard delivery is terminal-dependent and labelled requested, not confirmed. Copy is limited to the viewport and display-row line breaks; edge auto-scroll/double-click selection are not included.

Gruvbox Dark uses neutral bold and rules for the two major sections, bold category headings and bright neutral text for both bodies and metadata. Normal text never uses toned-down gray or terminal dim. Verified references use aqua; actual warnings/failures use orange or red, and selection uses yellow/reverse video. Missing evidence is neither green success nor red failure. Typed roles are presentation-only and absent from stored text and CLI exports; NO_COLOR preserves structure and selection. No terminal background or host theme settings are changed.

h opens **전체 기록 · 읽기 전용**, replacing the old history expansion/collapse. Scope/content are frozen at opening. Nine categories expose all today's completions, valid decisions, recorded progress/blockers/actions, previous/unknown-time records, user-excluded records, legacy/unlinked records, versions/evidence, scope/time/collection details and record-summary processing details. Main-view grouping does not delete or cap this reader; render-history retains its full branch export contract. The summary/processing category preserves the exact technical diagnostic and labels the processing-status record's own timestamp, separate from the source conversation's last inclusion time. An effective-language change rebuilds authored titles and rows from the captured typed snapshot, retaining category, content, capture time and logical scroll anchor; it does not query a newer record set. Transient authored notices are cleared without discarding editor/link input drafts.

m, F10 or right click opens the menu with read-only **저장 기록 보기 / View saved records** first, **요약 모델… / Summary model…** second, **언어 / Language…** third and current progress fourth. Simple action labels and a right-aligned shortcut column distinguish actions from keys. The advertised h/l/e/o/s/b/r/v/q keys work inside the open menu; q hides the panel and Esc closes only the menu. Model/language/progress rows use arrows and Enter without extra keys. The menu retains one active navigation footer, with a minimum-width guard where actions cannot be shown safely. Progress details expose public explanations, plans, activity metadata, temporary summaries, the full recent request and source clocks still retained in the current cache. This is the collected cache, not every past dialogue message or raw tool output. Saved evidence/corrections remain the separate e editor.

Arrows/j/k, PageUp/PageDown, Home/End and wheel scroll readers; left/right or [/] change category. Resize preserves the same logical record. Esc/h/q closes only the reader and restores main scroll. Other commands, including s/r/v/Enter/e/m, are consumed: no model, GitHub lookup, capture request or journal mutation.

b and the explicit date menu action open a process-local picker. Up/down selects a date, Enter requests that date's captured pending IDs, Esc cancels. Date navigation invokes no model/GitHub and does not modify journal/participation. Unknown/cross-midnight turns remain separate. Extra today turns held by three-turn reactivation remain selectable under today. While the date picker is open, m/F10/right click are consumed; they cannot open another overlay or bypass the picker. Esc cancels and Enter requests the selected date.

The single main footer shows the visible row range/total and a cue when more content is below. It visibly names r as “r 반영,” alongside l/e/h/m when they fit. Labels use actual terminal cell width; narrower variants retain r with h/m before dropping supporting text or the row range. At extremely small widths the r hint takes priority. Existing o/s/b/q shortcuts remain supported and their actions remain available in the menu. v refreshes work references from the main view or link picker; r keeps its main-view reflection meaning. Uppercase R has no action. Read-only viewing comes first; panel hiding/collection stopping comes later. e retains evidence/amend/exclude/undo with explicit preview/save. Link assignment retains active-client, revision and source barriers.

r requests reflection/retry of captured, unreflected completed turns eligible for today. It is not a read-only recheck. It still clears a previous manual-date request and resets retry budgets, then starts the existing worker only when eligible completed turns exist. The panel distinguishes a reflection request, no eligible completed turn (with held-date or incomplete-response guidance), and an error. Previous/held dates remain selected through b; r does not enable stopped collection, import whole transcripts or erase past gaps. “마지막 반영” remains the source conversation time, not the time r was pressed.

“Maeklog 끄기 · 이 탭” cancels collection/reduction and hides the panel. “패널만 숨기기 · 수집 계속” and main q/Esc only hide it. The Maeklog content menu differs from Herdr's titlebar/Close pane menu. Focus/startup never re-enable opt-out.

Rendering and reader navigation invoke neither a reducer nor GitHub and write no journal. Independent pending-work recovery retains its old behavior; opening a reader does not request it.

## Certainty and follow-ups

A persisted decision requires explicit user confirmation; proposals are not active decisions. Implementation completion never retires the decision. Every completion is displayed as a report, including verification/deployment reports; Maeklog performs no independent verification.

Original completion/failure entries remain visible in history. A completion's latest linked descendant supplies its follow-up label. Unresolved failed/rework reports remain warned and fully readable by scrolling the default screen, including previous-date failures. No failure may be discoverable only by opening the history reader.

Blocker omission becomes unconfirmed while retaining its last source time. Only an explicit evidence-backed resolution removes it from the current selection. Newer successful completion reports do not resolve an older failed summary batch or a recorded blocker by themselves. Action conditions must wrap, not be dropped to make a one-line layout.

Legacy latest preview is labelled “잠정 · 누적 전”, never inserted among confirmed journal records. v0.12 does not create a duplicate preview call; it commits eligible latest work directly. Neither legacy preview nor current next-action text grants permission to act.

## Validation boundary

Isolated real PTY fixtures exercise crossterm navigation, copy, resize, scoped warnings and explicit actions using mock Herdr/GitHub/model processes.
