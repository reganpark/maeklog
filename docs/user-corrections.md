# 항목별 근거 보기와 사용자 정정 — v0.13.0

패널에서 `e`를 누르면 현재 브랜치에 저장된 결정·완료 목록이 열립니다. `↑↓`로 항목을 고른 뒤 `Enter`를 누르세요. 오기록으로 제외한 항목도 목록에 남습니다. 조회·편집 초안·취소는 모델이나 GitHub를 호출하지 않습니다.

## 근거 보기

현재 적용되는 내용·조건, 원래 기록의 근거 인용, 발언자, 발언 시각, Space·세션·턴을 표시합니다. 근거는 저장된 발췌이며 전체 대화 원문이 아닙니다. 사용자 정정 이력에는 수정 전후·사유·정정 시각과 정정한 Space가 별도로 표시됩니다. `j/k`, 방향키, 휠, PageUp/PageDown으로 긴 내용을 읽습니다.

## 정정과 되돌리기

- `e`: 내용과 조건 정정. Tab/Shift+Tab으로 내용 → 조건 → 사유를 이동합니다. 좌우/Home/End로 커서를 이동하고 Ctrl+U로 현재 칸을 비웁니다. 한글과 붙여넣기를 지원합니다. 내용 1,200자, 조건·사유 각각 600자 이내입니다. 빈 조건은 ‘조건 없음’입니다.
- `x`: 오기록으로 제외. 유효한 결정·최근 완료·완료 후 문제 목록에서 제외하지만 원문과 이력을 유지합니다. 잘못 기록된 질문을 제외하는 것은 실제 결정의 철회와 다릅니다.
- `u`: 아직 되돌리지 않은 마지막 사용자 정정을 되돌립니다. 여러 정정은 역순으로 되돌릴 수 있으며 되돌린 이력도 남습니다. 이후의 실제 결정 변경·철회 관계는 취소하지 않습니다.

모든 정정에는 사유가 필요합니다. 첫 Enter는 변경 전후와 공유 범위를 검토하는 화면을 열고, 그 화면의 Enter가 저장합니다. Esc는 확인 → 편집 → 근거 → 목록 → 원래 패널 순서로 돌아갑니다. 저장 전 Esc로 취소하면 기록을 바꾸지 않습니다.

v0.14부터 현재 탭의 저장소·브랜치 기록에만 적용됩니다. 다른 탭의 기록에는 반영하지 않습니다. 미연결 기록도 해당 탭 범위입니다. 다른 Space나 새 요약이 원장을 갱신했으면 오래된 편집을 저장하지 않고 오류를 표시합니다. `r`로 최신 기록을 다시 읽고 재편집하세요. 읽는 도중 브랜치가 바뀌면 저장을 막습니다.

## 보존 및 모델 처리

`journal.json`의 각 record에 `corrections` 이력을 추가합니다. 원래 versions·근거 인용·원본 시각은 수정하지 않습니다. 사용자 정정은 새 발언·새 승인·독립 검증을 뜻하지 않으며, 항목의 종류·작업 단계·보고 결과는 그대로입니다. 단계/결과 자체가 잘못된 항목은 오기록 제외를 사용하세요. 실제 결정을 바꾸거나 철회할 때는 작업 대화에 그 사실을 남깁니다.

모델에 제공하는 항목에는 정정된 내용·조건과 오기록 제외 표시를 전달합니다. 같은 원본 이벤트를 다른 키로 재처리해도 기존 중복 방지 기록이 복원을 막습니다. 제외한 항목은 모델이 관계 대상으로 사용할 수 없습니다. 정정 전에 시작한 모델 응답은 저장을 거부하고 최신 정정을 기준으로 다시 처리하며, 이 충돌은 기존 실패 재시도 횟수를 소모하지 않습니다.

진행·막힘·다음 행동의 사용자 편집과 기존 상태의 자동 재계산, 전체 과거 검색, 추가 과거 입력 검색은 이번 범위가 아닙니다. 기존 모델 입력 한도(기록 24개·상태 12개·12,000자)도 유지합니다. 새 근거의 의미를 잘못 해석하는 모델 오류까지 코드로 막을 수는 없습니다.

## 업데이트

정정 이력은 기존 필드가 없는 원장에서도 호환 로드됩니다. 최초 조회만으로 파일을 이관하거나 다시 쓰지 않습니다. 업그레이드는 실행 중인 이전 버전 요약이 끝난 뒤 main/hook 실행 파일과 열린 Maeklog 패널에 함께 적용합니다. 정정 후에는 이전 바이너리만 덮어써서 다운그레이드하지 마세요. 이전 버전은 새 정정 필드를 보존하지 못합니다.
