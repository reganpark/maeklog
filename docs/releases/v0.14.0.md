# Maeklog 0.14.0 — first public preview

Maeklog helps you pick up Codex work in Herdr by keeping decisions, reported completions, progress, blockers and next actions beside your terminal. This is the first public **pre-release**, intended for early users who are comfortable building from source.

## What is included

- Separate records for each Herdr tab, including tabs working in the same repository and branch.
- Saved decisions and completion reports with source quotations, timestamps, corrections and history.
- Current public progress, blockers and next actions, including their owners and conditions.
- GitHub issue and PR references that you can inspect and correct.
- Configurable summary model and reasoning effort, plus Auto, English and Korean interface languages.

Completion entries record what the conversation reported. They are not independent verification of implementation, tests, merges or deployment.

## Install and open

Use the [English setup guide](../setup.md). It selects the `v0.14.0` tag and covers the build, four Codex hook approvals, the integrated Codex client and first-use checks.

Installation requires **Herdr 0.8.2 or later** and a **Maeklog-compatible Codex 0.162.1** client built from source. The client build requires **Bazel 9.2.0**, or Bazelisk providing the matching `bazel` command, alongside the other tools listed in the guide. Allow time and disk space for both builds.

After setup, run this in a regular Herdr shell in your project tab:

```sh
herdr plugin action invoke open --plugin maeklog
```

Click the panel to focus it. Press `m` or `F10`, or right-click, to open the menu. Use `h` for saved records, `e` for evidence and corrections, and `q` to hide the panel. See the [README key reference](../../README.md#day-to-day-use) for the other controls and optional Herdr shortcuts.

This release provides source installation and does not include ready-to-run client binaries. The repository has automatic discovery enabled in [Herdr Marketplace](https://herdr.dev/plugins/); the index refreshes every 30 minutes. Listing does not replace the hook approvals and integrated Codex client setup described in the guide.

macOS testing is welcome. When reporting a result, include the macOS version, Apple Silicon or Intel, Herdr version, Maeklog tag and the installation or runtime step you tested. Distinguish a successful build from a successful first conversation and saved record. Report problems through [GitHub Issues](https://github.com/reganpark/maeklog/issues), with a minimal reproduction and sanitized error output.

## Before your first conversation

- Summaries consume additional model usage. Selected conversation text and a limited index of existing records are sent to a model service through Codex. There is no monetary budget cap.
- Local records are not encrypted. Do not attach prompts, state directories, credentials or private terminal captures to a public issue; see the [security policy](../../SECURITY.md).
- Hiding the panel keeps collection running. Use **Stop recording in this tab** in the menu to stop collection and summaries for that tab.
- Earlier conversations are not imported automatically. Model access depends on your account, and summaries can be wrong; check the evidence for important records.
